# Intelligent-Processing-of-Scientific-Conference-Abstracts-and-Their-Classification
Итоговая аттестационная работа бакалавра на тему «Алгоритм очистки космических снимков от облаков». Работа выполнялась в учреждении высшего образования "Московский авиационный институт (национальный исследовательский университет)".
